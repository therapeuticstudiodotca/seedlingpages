# Seedling Pages

The site for seedlingpages.ca, a creative care practice from Therapeutic Studio. Plain HTML, no build step.

## Files

- `index.html` — the essay "The Root Goes First", the nine pages, the practice in nine pictures, and sources
- `gratitude.html` — whose work is present here
- `images/` — photographs (licensed by Therapeutic Studio), each used once
- `files/` — the workbook PDF and the blank fold-line pages (Letter and A4)
- `CNAME` — tells GitHub Pages the site lives at seedlingpages.ca

## To publish

Upload everything in this folder to the top level of the repository, then Settings → Pages → Deploy from a branch → main, root.
