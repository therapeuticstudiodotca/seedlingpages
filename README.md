# Seedling Pages

The site for seedlingpages.ca, a creative care practice from Therapeutic Studio. A sibling of Slow Leaf, built the same way: plain HTML pages, no build step.

## Files

- `index.html` — home
- `the-pages.html` — the eighteen drawings (placeholders until they arrive)
- `practicing.html` — the nine pictures, sowing and weaving
- `knowing-seed.html` — six notes with sources, and Gratitude
- `seed-atlas.html` — the map; its region data is embedded in the page
- `regions.json` — the same region data as a separate file, for reference
- `images/` — photographs (licensed by Therapeutic Studio), each used once across the site, and the workbook cover
- `files/` — the workbook PDF and the blank fold-line pages (Letter and A4)
- `CNAME` — tells GitHub Pages the site lives at seedlingpages.ca

## To publish

Upload everything in this folder to the top level of the repository, then follow the GitHub Pages steps (Settings → Pages → Deploy from a branch → main, root).

## Before going live

The Seed Atlas entries were researched from the sources listed with each region and then checked a second time. Both passes read the source pages through a summarising tool, so a person should open the links for any region they care most about and confirm the wording.
