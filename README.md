# Seedling Pages

The site for seedlingpages.ca, a creative care practice from Therapeutic Studio. Plain HTML, no build step.

## Files

- `index.html` — home: why the seed, a note on the medium, four ways in, the workbook
- `the-pages.html` — the ten pages to print
- `folding-and-sowing.html` — pictures 1–8, the strip, sowing
- `weaving.html` — weaving the strips
- `the-root-goes-first.html` — the essay, with sources
- `gratitude.html` — whose work is present here

Each page draws its photographs from one colour story. Photographer credits go where the `<!-- CREDIT -->` comments are; video slots are marked `<!-- VIDEO SLOT -->`.
- `images/` — photographs (licensed by Therapeutic Studio), each used once
- `files/` — the workbook PDF (landscape Letter)
- `pages/` — the ten drawings, one printable PDF and one preview image each, plus all ten in one PDF
- `CNAME` — tells GitHub Pages the site lives at seedlingpages.ca

## To publish

Upload everything in this folder to the top level of the repository, then Settings → Pages → Deploy from a branch → main, root.
